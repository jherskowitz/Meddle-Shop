# Meddle Shop

A one-man maker studio of software, hardware, photography, music, and more.

**Live site:** [meddleshop.com](https://jherskowitz.github.io/Meddle-Shop/)

## About

Meddle Shop is a portfolio site built with plain HTML, CSS, and vanilla JavaScript. No frameworks, no build tools, no dependencies.

## Local Development

Open `index.html` in a browser. That's it.
